# Use RTI to Nudge Action on Unanswered Grievances

If a grievance petition you filed has gone unanswered or unattended, file an RTI
to the **same department** asking for the complete file related to your complaint,
including:

- All file notings by concerned officials
- Internal and external correspondence related to your complaint ID

## Why this works

Officials are duty-bound not to keep a file sitting at any particular desk beyond
a stipulated time period. Once an RTI is filed, the file movement and the notings
on it become traceable and disclosable.

This creates accountability — the RTI forces the file out of inaction because now
the department has to respond to *two* things: the original grievance and the RTI.

## Practical tip

Quote your **complaint ID / grievance registration number** explicitly in the RTI
application so there is no ambiguity about which file you are seeking.
